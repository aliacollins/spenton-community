# Report a security issue

Send suspected vulnerabilities privately to **privacy@spenton.dev**, with
“SpentOn security report” in the subject. You can also use this repository's
[private vulnerability report](https://github.com/aliacollins/spenton-community/security/advisories/new).

Include the affected version, Cloud or self-hosted context, expected and actual
behavior, potential impact, and reproduction steps using fictional data.
Do not send passwords, cookies, API keys, private keys, real receipts or other
people's financial records. Ask before attaching sensitive evidence.

Avoid publishing unpatched vulnerability details in issues. Test only on
installations and accounts you control. Do not access other people's records,
disrupt shared services or test payment providers without authorization.

The maintainer will assess reports and coordinate fixes and disclosure. No
bounty or guaranteed response time is offered. Security fixes currently target
the latest beta release; support for older versions is not established.

This release is not end-to-end encrypted. Operators must protect the server,
its database, private settings and backup volumes. See [SETUP.md](SETUP.md).

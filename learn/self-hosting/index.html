Start SpentOn with Docker.

Run Docker, open SpentOn and choose a username and password. No email service, domain or separate Node.js installation is needed.

Public GitHub release coming soon.

The source package is in its final distribution review. These are the setup steps for the upcoming release.

1. Start Docker

With Docker and Compose installed, open a terminal in the SpentOn source folder and run:

docker compose -f self-hosted/compose.yaml up -d --build

The first build takes a few minutes. SpentOn generates its private settings and starts the app and backup service automatically.

2. Create your local account

Open localhost:8080 on the computer running Docker. Choose a username and a password of at least 12 characters, then start your budget.

Your account belongs to this installation. No email address, verification message or Cloud subscription is needed. The default setup is accessible only from that computer.

3. Keep your data

Accounts, budgets and private settings stay in Docker volumes when the app restarts or updates. The backup service keeps daily snapshots in a separate volume. Keep a protected copy off the computer as well.

To update, use the next source release and run the same command with the same volumes. Do not run docker compose down -v: it deletes the stored volumes.

If you forget your password

Reset a local password without email

On the computer running SpentOn, run:

docker compose -f self-hosted/compose.yaml exec app node self-hosted/reset-password.mjs

Enter the username and a new password when prompted. Passwords are hidden as you type. Existing sessions are signed out; your budgets stay saved.

Need help? Ask in r/Spenton. Share the error message without passwords or personal records.
